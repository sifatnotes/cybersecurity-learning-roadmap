# 🔐 Cybersecurity Learning Roadmap

A practical roadmap for learning cybersecurity from beginner to advanced level.

This roadmap is designed for students, beginners, aspiring ethical hackers, penetration testers, SOC analysts, security researchers, bug bounty hunters, and anyone who wants to build practical cybersecurity skills.

> **Learn → Practice → Build → Document → Repeat**

---

# 1. 💻 Computer Fundamentals

Before diving into cybersecurity, understand how computers actually work.

### Learn:

* Operating systems
* Files and directories
* Processes
* Memory
* CPU basics
* Users and permissions
* Software and applications
* Virtual machines
* Basic troubleshooting

### Goal

You should be comfortable navigating an operating system and understanding what happens when you run a program.

---

# 2. 🌐 Networking Fundamentals

Networking is one of the most important foundations of cybersecurity.

### Learn:

* OSI model
* TCP/IP
* IPv4 and IPv6
* Subnetting
* MAC addresses
* DNS
* DHCP
* HTTP and HTTPS
* TCP and UDP
* Ports
* Routing
* NAT
* Firewalls
* VPNs
* Proxies

### Practice

Try to understand network traffic rather than simply memorizing definitions.

Useful tools:

* Wireshark
* Nmap
* tcpdump

---

# 💡 How to Actually Learn Cybersecurity

A simple approach:

```text
20% Theory
    +
60% Hands-on Practice
    +
20% Documentation
```

Don't wait until you "know enough" before practicing.

Learn a concept.

Practice it.

Make mistakes.

Figure out why it failed.

Document what you learned.

Then move to the next topic.

---

# 🚫 Common Mistakes Beginners Make

### ❌ Trying to learn everything

Cybersecurity is too broad to master everything at once.

### ❌ Watching endless tutorials

Practice is more valuable than endlessly consuming content.

### ❌ Ignoring networking

Networking becomes important in almost every security specialization.

### ❌ Avoiding Linux

Linux skills are extremely useful in many cybersecurity roles.

### ❌ Collecting certificates without skills

Build projects and practical experience alongside certifications.

### ❌ Practicing on unauthorized targets

Only test systems you own or have explicit permission to test.
